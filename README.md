# copilot-review-demo

Demo repository for evaluating GitHub Copilot code review as a **first-pass reviewer** on pull requests — before a human reviewer takes a look.

## What we're evaluating

- How Copilot reviews a pull request when requested (or assigned) on a PR.
- The quality and actionability of its suggestions on small, incremental changes.
- Whether it makes sense as a pre-review step in our team's PR workflow.

See `NOTES.md` (added via a branch and pull request) for trial notes.
